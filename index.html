You are running the Desktop Edition — updates arrive right here under Help.

  • Its own app window — not a browser tab, no Chrome needed
  • Works 100% offline — your photos never leave your PC

Download Setup for Windows
  1. Download the setup ZIP
  2. Right-click it → Extract All…
  3. Double-click “Install SHIVAM PIXA”
  4. The app opens in its own window — Desktop + Start Menu icons ready

Needs internet once for the first open; after that everything works offline. If Windows SmartScreen asks, choose “More info” → “Run anyway”.
